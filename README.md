# Pi-Socket-Server
A WebSocket server/framework intended for usage on a pi in order to enable modem-less
communication between computers on a server or even between servers

Currently supports:
  - User registration
  - Payload/message tunneling between clients
  - Payload/message broadcasting between clients
  - Requests to server

Future additions:
  - Different request types

Usage:
  - Pull, maybe adjust port and run
  - You will need something that allows you to expose your computer to the WAN like NGROK or Port Forwarding or tailscale
